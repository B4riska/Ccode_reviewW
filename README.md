# Steam-Game-Collector
### Описание
 Проект позволяет извлекать информацию о играх с веб-сайта Steam, такую как название, дата релиза, цена, разработчик и ссылка на поисковый запрос в steam. 
 Полученные парсером данные хранятся в SQLite.  После обновления пользователь может просмотреть полученные данные на веб-странице проекта.
### Как работает?
1.    **Запуск парсера parser.py:** Парсер начинает собирать данные с Steam и сохраняет их в базу данных.
2. **Просмотр списка игр:** На странице **db.html** отображается таблица с информацией о играх.
3. **Фильтрация:** После нажатия кнопки "Сортировать" на странице **db.html**, Flask-приложение фильтрует игры по указанной цене и отображает результат на странице **filtered_games.html**.
### Как установить?
###### 1. Убедитесь, что у вас установлен Docker, а Docker Desktop(Engine) запущен. 
###### 2. Клонируйте репозиторий: 
    ```bash
    git clone https://github.com/fel1k2/Python-MIPT.git
    ```
###### 3. Перейдите в директорию проекта:
    ```bash
    cd Ccode_reviewW
    ```

###### 4. Соберите и запустите контейнеры Docker:
    ```bash
    docker-compose up --build
    ```

###### 5. Откройте веб-приложение: Перейдите в браузере по адресу **http://127.0.0.1:8000/**
